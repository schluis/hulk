Filter integration findings (2026-10-03)
- Prediction now integrates damping/process covariance over elapsed time using
  the existing 2ms reference period. No parameter schema change. Default .998
  velocity factor remains exact at2ms; position integration differs about0.1%.
- Resting hypotheses can recover motion from three associated, statistically
  significant, direction/speed-consistent observations. History follows Ground
  odometry; long gaps restart evidence rather than averaging across unknown kicks.
- Successful merges retain the newest last_seen; rejected mode merges do nothing.
- Selection recovery must preserve ordinary accumulated-confidence competition.
  A global confidence cap regressed training closeRMSE .892->1.248. A120ms grace
  alone did not resolve this. Final narrow stale-track recovery:
  only a confirmed fresher challenger can override an incumbent unobserved120ms.
  Compare prior-weighted capped confidence only for that recovery decision.
- Identical-input evaluation uses the six existing single-prior MCAPs, unchanged
  baseline and round76 parameter sets, and the existing scoring implementation.
  This is algorithm comparison, not a claim that new output exactly reproduces
  an old algorithm's recorded output. Fresh captures still need exact replay.
- Current detection_noise is a radius-relative pixel standard deviation, not
  pixels:5*observed_radius. For the simulator's0.105m ball this can imply roughly
  .525m lateral Ground sigma. Three-sigma adjacent-frame motion evidence is then
  deliberately hard to establish. Calibrate uncertainty instead of weakening
  the significance guard to fit a recording; old optimized noise is also~5.
- Association uses prediction covariance P alone rather than innovation P+R.
  This can couple noise tuning to association through posterior inflation.
  Follow-up inside filter: uncertainty-aware association and separate validation
  of false bursts, contacts, and low-noise coherent motion.
- Track identity/switch hysteresis remains a follow-up: a recently selected
  challenger can lose confidence during occlusion and revert to an older track.
  Fixed-image false bursts can imitate Ground motion while the head moves.
- Duplicate observations do not add per-track confidence or motion evidence,
  but duplicate whole batches still decay confidence. Current FutureMap emits
  finalized batches once; this is not general replay idempotence.
- Image-time Ground and latest odometry-time Ground can differ between samples.
  Normally<=2ms at500Hz; missing odometry can make this large. Follow-up inside
  filter: explicit exposure-time alignment or bounded evidence age/reset.
- New MotionEvidence is explicit in serde and Message diagnostic schemas.
  Rebuild full-filter diagnostic consumers (including Twix map layer) together.
  BallPosition, percept, parameter, and recording input schemas are unchanged.
